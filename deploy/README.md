Upload your Letterboxd export and get film recommendations, from three signals: TMDB rating, content similarity (description embeddings) and taste similarity (MovieLens).

Code and evaluation: https://github.com/Nafety/movies-recommandations

This product uses the TMDB API but is not endorsed or certified by TMDB.
